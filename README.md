# Hola, soy Alfonso

Estudio cuarto de Ingeniería Informática en la Universidad de Salamanca. Este repositorio solo contiene esta página de presentación.

## Sobre mí

Me interesa sobre todo la ciberseguridad: criptografía, sistemas seguros y todo lo que tenga que ver con proteger infraestructura. También disfruto con el desarrollo backend y el diseño de APIs REST. Aprendo mejor haciendo cosas, así que dedico tiempo a laboratorios, CTFs y proyectos personales. Fuera del código, voy al gimnasio.

## Tecnologías

Lenguajes que uso: Python, Java, C/C++, JavaScript/TypeScript, Bash y SQL. Ahora estoy aprendiendo Rust.

En backend he trabajado con Node.js (APIs REST y microservicios), Spring Boot a nivel básico y React en la parte de frontend.

En sistemas me muevo en Linux (Kali y Ubuntu), uso Git con GitHub y GitLab CI/CD, y tengo nociones de Docker. Para seguridad y redes uso Nmap, Wireshark y OpenSSL.

## Ciberseguridad

He hecho laboratorios de análisis de tráfico y de bastionado de sistemas, prácticas con certificados digitales, TLS y cifrado (RSA, ECC y AES), y he usado herramientas de pentesting en entornos controlados.
